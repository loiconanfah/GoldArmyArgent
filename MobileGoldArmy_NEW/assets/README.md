# Assets Directory

Placez vos assets ici :

- `icon.png` - Icône de l'application (1024x1024 px)
- `splash-icon.png` - Icône pour le splash screen
- `android-icon-foreground.png` - Icône Android foreground
- `android-icon-background.png` - Icône Android background
- `favicon.png` - Favicon pour le web

Pour l'instant, ces fichiers sont optionnels. L'application fonctionnera sans eux, mais vous verrez des avertissements.
